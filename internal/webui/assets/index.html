WHAT IS MEASUREDstays on this machine

Measured: how long each key is held and the gap before the next one, in milliseconds, while this console has focus and PULSE is on.

Never recorded: which keys you press, or anything typed outside this page. The browser pairs a press with its release and sends only the two numbers.

Kept: four numbers — your typical hold time and gap, and how much each varies. They are saved in modules.json so the profile survives a restart. FORGET PROFILE deletes them.

What happens on a mismatch: two consecutive 50-key windows that do not look like the enrolled rhythm raise a critical alert and, if you turn it on, lock the screen.

This is a tripwire for someone else sitting down at an unlocked machine, not proof of identity. Being tired, typing one-handed or using another keyboard all change your rhythm.

▚ BOARDS ON USB

    
Plug a board into its UART (or COM) USB-C port. NetWatch writes the firmware and these settings to it; after that it only needs power, from either port. The password goes to the board and is kept in NetWatch's memory until it stops — it is not written to this machine's disk.
